# lever-vote

Live audience poll for the talk "Would You Pull the Lever?". One Python file, standard library only.

- `/` is the audience page. Phones vote here, one vote per browser per poll.
- `/screen` is the projector view. It shows the join QR code and the results.
- `/admin` is the presenter page. It needs the admin key. Arrow keys move between polls, `R` toggles results, `O` toggles voting.

## Run

```sh
VOTE_ADMIN_KEY=change-me python3 app.py      # serves on :8080
python3 test_app.py                          # end-to-end check
```

Optional environment: `VOTE_PORT` (8080), `VOTE_STATE` (state.json), `VOTE_POLLS` (polls.json).

Put a QR code for your public URL at `static/qr.png`, for example `qrencode -o static/qr.png https://vote.example.com`.

## Polls

`polls.json` and `static/art/p*.jpg` are generated by `make_polls.py POLLS_MD ART_DIR`. Edit `polls.json` by hand to change the questions.

## Deploy

`deploy.sh` copies the app into a Proxmox container that runs it as the `lever-vote` systemd unit. Set `DEPLOY_HOST`, `DEPLOY_CT`, and optionally `DEPLOY_URL`.
